1단계 · 지시문을 붙여넣기

AI-시작지시문.txt 를 열어 선 안쪽 전체를 복사해서 ChatGPT에 붙여넣고 보냅니다.

길어도 괜찮습니다. 통째로 넣는 것이 중요합니다 — 홈페이지의 규칙이 모두 들어 있습니다.

2단계 · 저장소를 연결하라고 하면

화면 안내를 따라가세요. 모르는 화면이 나오면 ChatGPT에게 그대로 물어보세요.

이렇게 물어보세요 → “지금 화면에 ○○ 라고 나오는데 어디를 눌러야 하나요?”

AI는 자기 화면을 잘 안내합니다. 혼자 추측해서 누르지 마세요.

3단계 · 미리보기 주소를 열어 눈으로 확인 — 가장 중요

작업이 끝나면 AI가 이런 주소를 줍니다.

https://kclc-website-git-○○○-kclc.vercel.app

그 주소를 직접 열어 아래를 확인하세요.

  • 화면 맨 위에 공지 띠가 보이는가
  • 글씨가 깨지거나 겹치지 않는가
  • 오른쪽 위 English 를 눌러 영어 쪽도 제대로 나오는가
  • 휴대폰으로도 열어보기 (글자가 화면 밖으로 넘지 않는지)

미리보기는 연습용 복사본입니다. 여기가 아무리 이상해도 실제 홈페이지는 멀쩡합니다.

4단계 · 이번에는 합치지 않고 끝냅니다

이렇게 말하세요 → “확인했습니다. 이번 건은 실제 사이트에 올리지 말고 취소해 주세요.”

끝입니다. 실제 홈페이지는 처음과 똑같습니다.

나중에 진짜로 올리고 싶을 때만 “실제 사이트에 올려 주세요”라고 하면 됩니다. 그때는 미리보기에서 반드시 눈으로 확인한 뒤에 말씀하세요.

이런 말이 나오면 믿지 마세요

AI가 이렇게 하면이렇게 하세요
미리보기 주소 없이 “다 됐습니다”“미리보기 주소를 알려주세요” 라고 요구
코드를 어디에 붙여넣으라고 함하지 마세요. 붙여넣기는 필요 없습니다
비밀번호·환경변수 값을 물어봄절대 알려주지 마세요. 필요 없는 작업입니다
“master 에 바로 올렸습니다”규칙 위반입니다. 담당자에게 알려주세요
상담 요청 양식을 고쳤다고 함손대면 안 되는 곳입니다. 담당자에게 알려주세요

AI는 “다 됐습니다”라고 말하면서 틀릴 수 있습니다. 미리보기를 직접 보기 전까지 믿지 않는 것이 이 방식의 핵심입니다. 의심하는 것은 실례가 아니라 정상적인 절차입니다.

안심하셔도 되는 이유

깨진 사이트는 못 올라갑니다 코드가 잘못되면 배포 자체가 실패하고 기존 홈페이지가 그대로 유지됩니다
공지는 스스로 사라집니다 끝나는 날짜가 지나면 자동으로 내려갑니다. 잊어버려도 괜찮습니다
