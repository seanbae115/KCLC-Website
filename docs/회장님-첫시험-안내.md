# KSLC 홈페이지 — AI로 처음 수정해보기

**이번은 연습입니다. 실제 홈페이지는 바뀌지 않습니다.** 마음 편히 해보세요.
잘못 눌러도 실제 사이트는 그대로입니다 — 마지막 단계(합치기)를 하지 않기 때문입니다.

---

## 준비물

| | |
|---|---|
| ChatGPT | 저장소(GitHub)에 연결할 수 있는 유료 플랜 |
| 저장소 주소 | `https://github.com/seanbae115/KCLC-Website` |
| 시작 지시문 | `docs/AI-시작지시문.txt` 파일 내용 전체 |

---

## 1단계 · 지시문을 붙여넣기

`AI-시작지시문.txt` 를 열어 **선 안쪽 전체를 복사**해서 ChatGPT에 붙여넣고 보내세요.

> 길어도 괜찮습니다. 통째로 넣는 것이 중요합니다 — 홈페이지의 규칙이 다 들어 있습니다.

## 2단계 · 저장소를 연결하라고 하면

ChatGPT가 "저장소에 연결이 필요하다"고 하면 화면 안내를 따라가세요.

**모르는 화면이 나오면 ChatGPT에게 그대로 물어보세요.**

> "지금 화면에 ○○ 라고 나오는데 어디를 눌러야 하나요?"

AI가 자기 화면은 잘 안내합니다. 혼자 추측해서 누르지 마세요.

## 3단계 · 미리보기 주소를 받아 열어보기

AI가 작업을 마치면 이런 주소를 줍니다.

```
https://kclc-website-git-○○○-kclc.vercel.app
```

**그 주소를 직접 열어서 눈으로 확인하세요.** 이게 가장 중요한 단계입니다.

확인할 것:
- [ ] 화면 **맨 위에 공지 띠**가 보이는가
- [ ] 글씨가 깨지거나 겹치지 않는가
- [ ] 오른쪽 위 **English** 를 눌러 **영어 쪽도** 제대로 나오는가
- [ ] 휴대폰으로도 열어보기 (글자가 화면을 넘지 않는지)

> 미리보기는 **연습용 복사본**입니다. 여기서 아무리 이상해도 실제 홈페이지는 멀쩡합니다.

## 4단계 · 이번에는 합치지 않고 끝냅니다

확인이 끝나면 ChatGPT에 이렇게 말하세요.

> "확인했습니다. 이번 건은 실제 사이트에 올리지 말고 취소해 주세요."

**끝입니다.** 실제 홈페이지는 처음과 똑같습니다.

> 나중에 진짜로 올리고 싶을 때만 "실제 사이트에 올려 주세요"라고 하면 됩니다.
> 그때는 미리보기에서 **반드시 눈으로 확인한 뒤에** 말씀하세요.

---

## 이런 말이 나오면 믿지 마세요

| AI가 이렇게 하면 | 이렇게 하세요 |
|---|---|
| 미리보기 주소 없이 "다 됐습니다" | **"미리보기 주소를 알려주세요"** 라고 요구하세요 |
| 코드를 어디에 붙여넣으라고 함 | **하지 마세요.** 붙여넣기는 필요 없습니다 |
| 비밀번호·환경변수 값을 물어봄 | **절대 알려주지 마세요.** 필요 없는 작업입니다 |
| "master 에 바로 올렸습니다" | 규칙 위반입니다. 담당자에게 알려주세요 |
| 상담 요청 양식을 고쳤다고 함 | 손대면 안 되는 곳입니다. 담당자에게 알려주세요 |

**AI는 "다 됐습니다"라고 말하면서 틀릴 수 있습니다.** 미리보기를 직접 보기 전까지는
믿지 않는 것이 이 방식의 핵심입니다. 의심하는 게 실례가 아니라, 정상적인 절차입니다.

---

## 안심하셔도 되는 이유

1. **코드가 잘못되면 배포 자체가 실패하고, 기존 홈페이지가 그대로 유지됩니다.**
   깨진 사이트가 올라가는 일은 구조적으로 막혀 있습니다.
2. 공지 배너는 **끝나는 날짜가 지나면 스스로 사라집니다.** 잊어버려도 괜찮습니다.
3. 상담 접수가 고장나면 **매주 자동 점검이 경고 메일을 보냅니다.**
